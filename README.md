# Hệ thống đặt lịch khám tại phòng khám tư nhân

## Bài đánh giá 2 - Đề tài 6
Học phần: Lập trình mã nguồn mở

## Thành viên nhóm
1. Linh - Trưởng nhóm, Authentication & DevOps
2. Khúc Hảo - Backend & Database
3. Quỳnh - Frontend & Testing

## Công nghệ sử dụng
- Backend: Python FastAPI
- Frontend: HTML, CSS, JavaScript
- Database: PostgreSQL
- ORM: SQLAlchemy
- Authentication: JWT
- Deployment: Docker, Nginx
- Version Control: Git & GitHub

## Chức năng chính
- Đăng ký, đăng nhập và phân quyền
- Quản lý bác sĩ và chuyên khoa
- Đặt lịch, hủy lịch và đổi lịch khám
- Xác nhận lịch hẹn và check-in
- Ghi kết quả khám và lập hóa đơn
- Xem lịch sử khám bệnh

## Thành viên và phân công
Các thành viên phát triển trên nhánh riêng,
tạo Pull Request và review trước khi merge vào main.
